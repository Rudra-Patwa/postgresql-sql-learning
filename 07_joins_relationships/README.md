# Joins and Relationships

In this section, I am learning table relationships and SQL joins.
Joins are used to fetch data from multiple tables using a common column.

This is one of the most important topics in SQL.

---

## Why Do We Need Joins?

In real applications, data is not stored in one table.
It is split into multiple tables to avoid duplication.

Example:
- customers table stores customer details
- orders table stores order details

To get complete information, we need joins.

---

## Types of Relationships

- One-to-One
- One-to-Many
- Many-to-Many

In this section, I am mainly using **one-to-many** relationships.

---

## Join Types Covered

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN

Each join behaves differently and gives different results.

---

## Tables Used

- customers
- orders

These tables are created only for learning joins.
