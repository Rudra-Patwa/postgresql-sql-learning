# CRUD Operations

In this section, I am learning basic SQL operations used to work with data.
CRUD stands for Create, Read, Update, and Delete.

These are the most common operations used in any database application.

---

## What is CRUD?

- **Create** → insert new data
- **Read** → fetch data
- **Update** → modify existing data
- **Delete** → remove data

Almost every application uses these four operations.

## Important Note

Always use `WHERE` clause while updating or deleting data.
Without `WHERE`, all records can be affected.
