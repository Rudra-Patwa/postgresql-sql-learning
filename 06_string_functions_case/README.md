# String Functions and CASE Statement

In this section, I am learning string functions and the CASE statement in SQL.
These are used to clean data, format text, and create custom logic inside queries.

This section is very useful in real projects and interviews.

---

## What are String Functions?

String functions are used to work with text data.
They help in:
- changing text format
- extracting part of a string
- cleaning unwanted spaces
- replacing values

---

## What is CASE Statement?

CASE is used to apply conditions and return values based on logic.
It works like if-else in programming.

CASE is commonly used to:
- create categories
- label data
- apply business rules
