# SQL Clauses and Operators

In this section, I am learning SQL clauses and operators.
These are used to filter data, sort data, and control query results.

This section helps in writing meaningful queries instead of selecting everything.

---

## What are SQL Clauses?

Clauses are keywords used with SELECT to control how data is fetched.

Some common clauses are:
- WHERE
- ORDER BY
- LIMIT

---

## What are Operators?

Operators are used inside conditions.

Examples:
- comparison operators (=, >, <)
- logical operators (AND, OR, NOT)

---

## What I Practice Here

- Filtering rows using WHERE
- Sorting data using ORDER BY

## Why This Section is Important

Almost all real SQL queries use:
- WHERE
- operators
- sorting
- limits
