# Learn SQL with PostgreSQL

This repository documents my step-by-step journey of learning SQL using PostgreSQL.
It is created as a structured learning and revision resource with clear examples
and simple explanations.

The goal of this repository is to build strong SQL fundamentals and practice
writing clean and logical queries.

---

## Why This Repository?

While learning SQL, I wanted a place where:
- concepts are organized properly
- examples are easy to understand
- learning can be revised anytime
- others can also benefit from it

This repository is the result of that approach.

---

## How to Use This Repository

1. Start from `00_introduction`
2. Follow folders in order (01, 02, 03...)
3. Read the `README.md` inside each folder
4. Run the `.sql` files using PostgreSQL / pgAdmin
5. Modify queries and observe the output
6. Revisit sections anytime for revision

## Learning Approach

- Focus on understanding concepts, not memorizing syntax
- Practice queries with real examples
- Write clean and readable SQL
- Learn why a query works, not just how

Common beginner mistakes are avoided intentionally in examples.
