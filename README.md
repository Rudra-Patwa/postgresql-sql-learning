
Each folder focuses on one SQL topic and contains:
- explanation (README)
- practical SQL examples
- realistic tables and data

---

## Topics Covered

- SQL basics and PostgreSQL overview  
- Database and table creation  
- CRUD operations  
- Data types and constraints  
- SQL clauses and operators  
- Aggregate functions and grouping  
- String functions and CASE statements  
- Table relationships and joins  
- Views and stored procedures  

---

## Tools Used

- PostgreSQL
- pgAdmin
- GitHub Desktop

---

## Learning Approach

- Focus on understanding concepts, not memorizing syntax
- Practice queries with real examples
- Write clean and readable SQL
- Learn why a query works, not just how

Common beginner mistakes are avoided intentionally in examples.

---

## Who This Repository Is For

- Beginners learning SQL from scratch
- Students preparing for SQL interviews
- Anyone looking to revise PostgreSQL fundamentals
