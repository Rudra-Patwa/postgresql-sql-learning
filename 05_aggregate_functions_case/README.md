# Aggregate Functions

In this section, I am learning aggregate functions in SQL.
Aggregate functions are used to perform calculations on multiple rows
and return a single result.

These functions are mostly used in reports, dashboards, and analytics.

---

## What are Aggregate Functions?

Aggregate functions work on a group of rows and return one value.

Common aggregate functions:
- COUNT
- SUM
- AVG
- MIN
- MAX

---

## Why Aggregate Functions are Important

Aggregate functions help answer questions like:
- How many records are there?
- What is the total value?
- What is the average?
- What is the highest or lowest value?

These types of questions are very common in real-world applications.
